# Reporting a security issue

Use GitHub’s private vulnerability reporting for this repository when available. Avoid public issues for credentials, personal data, or details of a security vulnerability. Include the affected revision, impact, and minimal reproduction. Redact network addresses, identifiers, keys, and private logs.

Ukor Visor controls devices on the local network. Review screenshots, logs, and packet captures before sharing them. The project does not require Roku account credentials.
