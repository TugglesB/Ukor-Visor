# Changelog

## Unreleased — Ukor Visor v1.0.0 release draft

Ukor Visor is a notch-based macOS remote for compatible Roku devices. This first public source release is planned to include:

- Directional navigation with key repeat, playback controls, and power and volume controls on compatible TVs.
- Keyboard input for Roku text fields and customizable channel shortcuts.
- Local-network device discovery and manual IPv4 setup.
- An in-visor Settings gear alongside the existing menu bar access.
- Optional Launch at Login and Reduce Motion support.

Requires an Apple Silicon Mac with macOS 14 or later. Build from source using Xcode. Live Private Listening is unavailable in this release.

Thanks to Scott Driggers and [Roam](https://github.com/msdrigg/Roam) for the Private Listening protocol reference.
